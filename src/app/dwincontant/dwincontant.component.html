How to Integrate Custom Images in DGUS Editor for HMI Design ?

Enhancing your Human-Machine Interface (HMI) with custom visuals not only improves user experience but also elevates the professionalism of your display. DGUS Editor simplifies this by allowing easy integration of custom images as part of your HMI project.

Why Use Custom Images?

Custom images can serve multiple purposes in an HMI system:

  • Buttons and Icons: Use images to create intuitive control buttons or functional icons.
  • Background Elements: Design visually appealing screens with themed or branded backgrounds.
  • Interactive Visuals: Enhance user interaction by linking image elements to touch events.
    • Steps to Integrate Images Using DGUS Editor

    1. Open the DGUS Editor software on your system to start your HMI design project.

    2. Navigate to the image library section and import your custom image files (BMP formats are usually supported).
