Introduction

Ultra-Wideband (UWB) is a high-precision wireless technology used for accurate distance measurement and real-time indoor positioning. It is widely used in industrial environments to track workers, machines, and assets.

In this system, UWB data is sent to MQTT using Embedded C. Then Node.js processes the data and forwards it to Acceedo Software to display the real-time position of the tag.

Calculation Logic

Main Concept

The distance between Anchor 1 and Anchor 2 is fixed and known in advance.

This known anchor distance becomes the foundation for calculating the tag position. Once the baseline is known, the system can use the live distance values from the tag to each anchor and derive the final coordinate output.

The distance from the following points changes continuously:

  • Anchor 1 to Tag
  • Anchor 2 to Tag

As the tag moves, these distance values change in real time. Because the movement is dynamic, the system must repeatedly measure and process the values in order to calculate the current location.

Using these measured values, the system calculates the tag position as (x, y). This means the tag is converted from a simple moving object into a precise coordinate point that can be shown visually inside the application.

Final Output: Tag Position = (x, y)

In simple terms, the concept is based on one fixed reference distance and two changing live distances. By combining these values, the system can estimate the exact location of the moving tag in a 2D coordinate space.

Learning Flow

How the System Works

A step-by-step overview of how the UWB-based industrial tracking system collects measurements, processes live data, and displays the final tag position in software.

01

Place the Anchors

Anchor 1 and Anchor 2 are placed in fixed positions inside the industrial area. These anchor positions are predefined and remain stable throughout the tracking process.

02

Define Anchor Distance

The distance between Anchor 1 and Anchor 2 is measured manually and stored as a constant value. This fixed measurement is one of the key inputs used in the final position calculation.

03

Move the Tag

The tag changes position continuously during movement. It may be attached to a worker, asset, or machine, depending on the industrial use case.

04

Measure Distances

UWB measures the distance from Anchor 1 to Tag and Anchor 2 to Tag. These values are updated continuously as the tag changes position in the working area.

05

Process the Data

The incoming values are received through the system and passed to the Node.js logic. The data is validated to ensure all required measurements are available before the position is calculated.

06

Calculate Position

Node.js uses the measured values and calculates the final tag position as (x, y). These coordinates represent the live location of the tag in the system.

07

Display in Software

The calculated result is sent to Acceedo Software, where the user can view the tag position, supporting values, and monitoring information in real time.

Communication Path

Data Flow

UWB Sensor
→
MQTT
→
Acceedo Software

UWB Sensor: The hardware layer responsible for generating raw distance measurement data between the anchors and the tags.

Embedded C: This programming layer handles the sensor logic and is responsible for publishing the captured UWB data to the MQTT broker.

MQTT Broker: Acts as the central communication bridge, efficiently transferring data packets from the hardware layer to the backend services.

Node.js: The backend processing layer that subscribes to MQTT topics, validates incoming data, and applies position calculation algorithms.

Acceedo Software: The final application layer that receives processed coordinates and displays the real-time position to the end user.

In this implementation, the function getTagLocation() acts as the main entry point. It reads the fixed distance from the company configuration and then checks whether the latest MQTT values are available.

Visual Understanding

Position Graph

The position graph helps users understand how the anchor points and the moving tag are represented visually. It makes the coordinate-based calculation easier to understand for both technical and non-technical users.

In a typical graph representation, Anchor 1 and Anchor 2 are placed on fixed points in the coordinate plane. The calculated tag position is then shown as a point based on the derived (x, y) values.

This visual representation is very helpful in industrial dashboards because it allows users to understand not only the raw numbers but also the actual location of the tag in a more intuitive way.
