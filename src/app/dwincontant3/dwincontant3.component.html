Text and ASCII Keyboard Configuration in DGUS Tool

This configuration allows users to input text through an on-screen keyboard and display it dynamically on the HMI screen. The ASCII keyboard is useful for fields such as names, IDs, and manual data entry. In this setup, the text display and input widgets are linked, enabling real-time character input and visualization.

Step-by-Step Instructions:

🔹
Step 1: In the Text Show module, click Text Display, drag the widget, and place it where the text should appear.
🔹
Step 3: Navigate to the Touch tab and select ASCII Input. Drag the widget and align it with the input area.
🔹
Step 5:
  • Set the Keyboard Location to refer to another page where the keyboard layout is placed.
  • Click Keyboard Setting to configure which keyboard layout to show.
🔹
Step 9: Click the Set button to apply the configuration.
🔹
Step 10: Enable the Keyboard Input option to activate keyboard function.
🔹
Step 11: The keyboard will now appear. Drag the widget again and align it with the text input area. Click OK to finalize.
⚠️
Note: Ensure the text display area and input widgets are properly linked in the Variable settings for real-time updates.
