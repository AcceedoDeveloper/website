Basic Touch and Keyboard Configuration in DGUS Editor

Designing user-friendly Human-Machine Interfaces (HMIs) often involves integrating input features like on-screen keyboards. The DGUS Editor provides a flexible way to implement custom touch-based keyboards for any industrial or consumer HMI project.

Virtual keyboards enable users to input text or numeric data directly on the HMI screen, making the system more interactive. This is especially useful for:

Why Configure a Virtual Keyboard in DGUS?

  • Data entry screens
  • Login/password fields
  • Search and control systems in embedded panels
    • 🔹
    Configuration Key Points:
    • Use high-quality keyboard images with clearly defined keys
    • Ensure touch areas slightly overlap visual key boundaries
    • Test each key's responsiveness after configuration
    • Consider adding visual feedback for key presses
    • Save keyboard configuration as a template for future projects
