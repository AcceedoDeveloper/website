Basic Touch and Keyboard Configuration in DGUS Editor

Designing user-friendly Human-Machine Interfaces (HMIs) often involves integrating input features like on-screen keyboards. The DGUS Editor provides a flexible way to implement custom touch-based keyboards for any industrial or consumer HMI project. In this guide, we’ll walk through the step-by-step process to configure a full QWERTY keyboard using the Basic Touch Module in DGUS Editor.
