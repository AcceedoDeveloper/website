NgRx - State Management for Angular

NgRx State Management

NgRx is RxJS powered global state management for Angular applications, inspired by Redux. It's a controlled state container designed to help write performant, consistent applications on top of Angular.
  • Centralized application state
  • Predictable state container
  • Inspired by Redux pattern
  • Reactive programming with RxJS
NgRx State Management Flow

1Actions

Define events that can change the state

Key Points:

  • Each action is like a message that says "this thing happened"
  • The format [Source] Event helps with debugging
  • Components or effects dispatch these actions
  • No logic here - just declarations of what can happen

2Reducer

Pure function that determines how state changes

Key Points:

  • Reducers must be pure functions (no side effects)
  • They take current state and return new state
  • The on() function associates actions with state changes
  • Initial state defines the starting value (0)

3Selectors

Efficiently get specific pieces of state

Why Use Selectors:

  • Avoid duplicating state access logic
  • Memoization (cache results until inputs change)
  • Can compose selectors together
  • Keep component code clean

4Store Registration

Make the store available throughout the app

What Happens:

  • The reducer is registered with the global store
  • The state will be accessible at state.counter
  • forRoot() sets up the store for the entire app

Display and interact with the counter state

  • State Access: store.select() gets current value
  • State Modification: Methods dispatch actions
  • Data Flow: User action → dispatch → reducer → store → selector → component
  • Async Pipe: Automatically handles subscriptions
