Sending UART Commands Using Docklight

Docklight is a serial communication tool used to test and send UART command frames to DWIN displays.

Step-by-Step Docklight Configuration:

🔹
Step 1:
  • Open the Docklight software
  • Set the serial port configuration:
    • Baud Rate: 115200
    • Parity: None
    • Data Bits: 8
    • Stop Bits: 1
🔹
Step 2: Enter the Write Command in Docklight (refer to example frame above). This command writes the value from VP into NOR Flash.
🔹
Step 3: Enter the Read Command to retrieve the data from NOR Flash back to VP.
🔹
Step 4: Reminder of essential VP addresses:
  • Machine No → 3002
  • Port No → 3004
  • Server Addr → 3006
🔹
Step 5:
  • Run the Write command to save data permanently
  • After success, restart the display to verify
🔹
Step 6:
  • Run the Read command to retrieve and load saved values from Flash into VP memory
  • You can now see this data reflected on your HMI
⚠️
Note: Always verify communication settings match your DWIN display configuration before sending commands.
