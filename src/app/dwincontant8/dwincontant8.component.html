Reading and Writing Data via UART Command Format

DWIN HMI displays support UART communication to store and retrieve data using onboard NOR Flash memory. This feature is crucial for retaining essential parameters such as machine IDs, server addresses, port numbers, and communication settings, even after a power cycle. It ensures system reliability by preserving configurations without manual re-entry. The use of NOR Flash offers stable, non-volatile storage, ideal for industrial and embedded systems. With UART-based access, updates can be done easily during runtime, making it a reliable and efficient solution for long-term deployment in automation, control panels, and smart interfaces.

NOR flash memory

But our Diwin Hmi support only NOR flash memory. NAND flash memory is not available for our Dwin Hmi. So, now I will store the data in Dwin nor flash memory.

This document explains how to use UART commands to:

  • Store data from a RAM (VP address) into the DWIN display's NOR Flash memory.
  • Retrieve the data from NOR Flash back into RAM (VP address).

Memory Type:

    1) VP (RAM)
  • Temporary memory used at runtime.
      • 2) NOR Flash
  • Permanent memory, used for data storage.

    • To write to NOR flash memory, the DWIN UART write command format is:

    [Header] [Length] [Command] [VP=0008] [Opcode=A5] [Flash_Addr] [VP_Addr] [Length]

    Eg: 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E

    • 1) Header 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E
    • 2) Length 5A A5 0B 00 08 A5 00 00 02 30 00 00 3E
  • Number of bytes after this byte, The hex value of (0x0B) is 11 it represent length of bytes.

    • Eg: 0B 82 00 08 A5 00 00 02 30 00 00 3E

    • 3) Command 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E
  • 0x82 - write to NOR flash.
  • But we are going to 0x82 command because we want to store data into NOR flash memory of Dwin Display.
    • 4) VP 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E
      i) VP_Highbyte=00
      ii) VP_Low byte = 08
  • This is a special address used to send Flash commands.
  • It tells the display: “This is not normal VP write. It’s a NOR Flash operation.”
    • 5) Opcode 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E
  • A5 = Write to Flash.
  • 5A = Read from Flash.
    • 6) Flash_Addr 5A A5 0B 82 00 08 A5 00 00 02 A5 30 00 00 3E
  • Head address of NOR flash address, Must be it should in even not in odd.
  • The range of NOR address is mentioned in dwin flash datasheet.
    • 7) VP_Addr 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E
  • VP address holding the data
    • 8) Length 5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E
  • Store no of length of bytes from VP address into NOR Flash address.

    • Summary:

    5A A5 0B 82 00 08 A5 00 00 02 30 00 00 3E

    According to the example we are saving 3E bytes of data from VP (0x3000) into NOR Flash memory (0x000002).

    Once this command is sent via UART, the HMI will permanently store the data in flash memory.
