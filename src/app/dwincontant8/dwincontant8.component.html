UART-Based Interaction with DWIN Display: Read & Write

UART communication allows the DWIN HMI to store and retrieve persistent data through command frames. This is essential for cases where values such as server settings, machine numbers, or user preferences need to be retained even after rebooting the display. With the help of Docklight or any serial terminal, we can issue write and read commands that interact with the device's NOR Flash memory using the special VP address 0x0008.

Step-by-Step Process:

🟢
Step 1: Enter the required data into the interface (e.g., machine number, port number, server ID).
🟢
Step 2: Run the Write Command via UART (Docklight) to store the entered data into NOR Flash.
🔁
Step 3: Restart the DWIN Display — You'll notice that the interface resets to default state after reboot.
🟢
Step 4: Run the Read Command — This loads the saved data from Flash back into the working VP address (RAM), making the values appear again.
✅
