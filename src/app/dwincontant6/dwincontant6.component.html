Reading and Writing Data via UART Command Format

DWIN displays support UART communication to store and retrieve data using NOR Flash memory. This is essential when working with parameters like machine IDs, server addresses, or port settings that need to persist even after a power cycle.

•
Supported Memory Types:
  • VP (RAM): Volatile memory; resets on power off
  • NOR Flash: Non-volatile memory; retains data after reboot
•
Functionality: Using UART commands, you can:
  • 📝 Write data from VP to Flash
  • 📤 Read data from Flash to VP

Key Components:

1.
Header (5A A5): Start of frame
2.
Length (0B): Number of bytes to follow
3.
Command (82): Instruction to write to NOR Flash
4.
VP (00 08): Flash operation indicator address
5.
Opcode (A5): A5 = Write | 5A = Read
6.
Flash Address (00 00 02): Destination address in Flash
7.
VP Address (30 00): Source address in RAM
8.
Length (00 3E): Number of bytes to copy
✅
This stores 62 bytes from VP 3000h into Flash 000002h.
