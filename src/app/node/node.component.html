Introduction to Node.js

Node.js is a JavaScript runtime environment that lets you run JavaScript code outside a web browser — mainly used to build backend (server-side) applications.

Think of it like this:

When you use JavaScript in a browser, it's for things like clicking buttons or changing webpage content. But with Node.js, you can use JavaScript to:

  • Create web servers
  • Read/write files
  • Connect to databases
  • Build APIs
  • Handle user requests

✅ Why use Node.js?

  • Fast — Uses Google's V8 JavaScript engine
  • Single language (JavaScript) — No need to switch between frontend and backend languages
  • Non-blocking I/O — Handles many users at once without getting slow
  • Huge library support — Thanks to npm (Node Package Manager)

Express.js Framework

What is Express.js?

  • Express.js is a web application framework for Node.js.
  • It simplifies the process of building server-side applications.
  • Known for its speed, minimalism, and flexibility.

Why Use Express.js?

  • Handles HTTP requests and responses.
  • Simplifies routing, middleware, and server creation.
  • Can be used to build RESTful APIs, websites, and single-page applications.

CRUD Operations with Node.js

✅ What is CRUD?

CRUD stands for:

  • C — Create (Add data)
  • R — Read (Get data)
  • U — Update (Change data)
  • D — Delete (Remove data)

These operations are common in any application that deals with a database (like users, products, tasks).

🛠 Technology Stack:

  • Node.js — Server
  • Express.js — Simplifies routes
  • JavaScript — Language
