API Concepts

🌐 What is an API?

API stands for Application Programming Interface.

An API allows two programs or systems to communicate with each other.

Simple Example:

Imagine you're at a restaurant:

  • You = Client (frontend)
  • Waiter = API (messenger)
  • Kitchen = Server (backend/database)

You tell the waiter what you want (a request), and the waiter brings you the food (a response). You don't need to know how the food is made — just order and receive.

✅ What Does an API Do?

  • Sends data from frontend to backend
  • Gets data from a server
  • Updates or deletes info from a database

📦 Common Types of APIs

Type Description
REST API Simple, uses HTTP methods (GET, POST, PUT, DELETE)
GraphQL API Flexible, ask only for the data you need
WebSocket API For real-time data (like chat apps)

💻 REST API Methods (CRUD Style)

Method Meaning Example URL
GET Read /users
POST Create /users
PUT Update /users/1
DELETE Delete /users/1

Postman

🚀 What is Postman?

Postman is a free tool used to test APIs (like your Node.js CRUD app). It helps you send HTTP requests (GET, POST, PUT, DELETE) to your server and view the response easily.

✅ Why Use Postman?

  • Test backend APIs (without writing frontend code)
  • Send data in JSON format
  • Check responses (status, body, headers)
  • Simulate real-world API calls
  • Automate and save API requests for later

postman's tools supports every stage of the API cycle: faster and easier API development without chaos

🧰 How to Use Postman for CRUD in Node.js

  1. Install Postman:

    Go to 👉 Postman Downloads

  2. Start Your Node.js Server

    Make sure it's running on http://localhost:3000

Postman Tips:
  • Use the "Save" button to save requests.
  • Use Collections to group related requests.
  • You can even automate testing with Test scripts (advanced).
MongoDB

🌱 What is MongoDB?

MongoDB is a NoSQL database where data is stored in JSON-like documents (not tables like in MySQL).

It's:

  • Flexible
  • Fast
  • Easy to scale
  • Perfect for Node.js apps

✅ Key Features

Feature Description
NoSQL Stores data as documents, not tables
JSON-like syntax Data is stored as BSON (like JSON)
Schema-less You can store any structure
High performance Good for large data and fast apps
