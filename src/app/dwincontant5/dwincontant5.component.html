Final Step: Saving and Exporting Project to SD Card

Role of the SD card

SD card act as a bridge, it enables communication between the software and display hardware. This ensures smooth rendering of visuals from the development environment onto the screen.

After designing and configuring the HMI interface, the final and essential step is to save the project and export it to an SD card for deployment to the DWIN display. This ensures the device boots up with the correct user interface and configuration settings. First, save your project and compile it using the DWIN development tool, which generates a folder—usually named DWIN_SET—containing all the necessary binary and resource files. Format an SD card to FAT32 (preferably 8GB–16GB), then copy the generated folder to the root directory of the card. Insert the SD card into the powered-off DWIN display, and then power it on. The device will automatically begin updating, displaying a progress bar. Once the update is complete, power off the device, remove the SD card, and restart the screen. Your custom HMI interface should now load and operate correctly on the DWIN display.
