Final Step: Saving and Exporting Project to SD Card

Once the HMI interface has been designed and configured, the final step is to save your project and transfer it to the DWIN display via an SD card. This process allows the DWIN device to boot up with the correct UI and configuration files.

Step-by-Step Instructions:

🔹
Step 1: Go to the File menu in DGUS Editor, then click Save and Generate. This will build the necessary project files for export.
🔹
Step 2:
  • Insert your Card Reader into a PC or Laptop
  • Format the SD card (recommended: FAT32 format) to ensure compatibility with the DWIN display
🔹
Step 4:
  • Eject the SD card safely
  • Power OFF the DWIN display
  • Insert the SD card into the DWIN SD slot
  • Wait for the configuration process to complete (usually within a few seconds). Once the screen lights up with the new interface, the process is complete
⚠️
Important: Always use a high-quality SD card (4GB-32GB recommended) and ensure proper ejection to prevent file corruption.
