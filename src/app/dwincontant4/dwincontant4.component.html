Variable Input Configuration in DGUS Tool

The Variable Input Configuration feature in the DGUS Editor allows users to input numeric or string data directly through the HMI screen. This input is then linked to a memory address, known as a Variable Pointer (VP).

For example:
  • You enter "123" as a machine number.
  • That value is written to a VP address (like 0x2000).
  • A display widget reads from 0x2000 and shows "123" on the screen.

This creates a real-time, two-way communication between the user and the system.

Why Use Variable Input?:

Using this feature is crucial for:

  • Setting machine numbers
  • Adjusting operational parameters (speed, time, pressure, etc.)
  • Logging and tracking runtime values
How to Configure Variable Input in DGUS Tool

Here's a step-by-step guide to configure variable input in your HMI project using the DGUS Editor:

Step 1:
  •   Open the Touch option and select the variable input
Step 2:
  •   Drag the widget and select the area.
Step 3:
  •   Set the VP address 3004(vp is must be even). here I choose the variable type as integer and size of integer digit is 4. Set the keyboard location as other page
  •   Click on keyboard setting, Now choose the keyboard page and setup the keyboard configuration by previous content (text display configuration using DGUS tool) step 5 to step 11.
Step 4:
  •   In the Text Show section, select Data Variable Display to visualize the value linked to the variable.
