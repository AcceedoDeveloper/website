Variable Input Configuration in DGUS Tool

The Variable Input Configuration feature in DGUS Editor enables numerical or string data entry that links directly to a memory address (VP). This is particularly helpful for settings like machine numbers, operational parameters, or runtime values. Through this setup, both data input and variable display are synchronized, providing dynamic feedback on the screen.

Configuration Steps:

🔹
Step 1: In the Touch module, choose Variable Input.
🔹
Step 2: Drag the Variable Input Widget to the appropriate area on the screen.
🔹
Step 4: In the Text Show section, select Data Variable Display to visualize the value linked to the variable.
🔹
Step 5: Drag the Variable Display Widget to the screen where data should be shown.

Additional Setup for Machine Number Configuration:

To configure a field like Machine No., follow the above steps and ensure the following key points:

✅
  • Use the Data Variable and Data Input options.
  • The VP address (Variable Pointer) should be the same and even for both input and display.
  • Set the Variable Type to Integer (Int) for both widgets.
  • Define the Size of the Integer Digit (e.g., 3 digits, 5 digits) in both places.
  • Make sure the Keyboard Setting is properly configured under "Data Input."
⚠️
Note: This configuration ensures that when a user inputs a value, such as a machine number, the HMI reads, stores, and displays it accurately using the VP address as a reference.
